Remote MCP endpoint

Add this URL as a remote MCP server in a compatible AI host. Or use the JSON configuration in clients that support it.

https://signalforge-web-production.up.railway.app/mcp

CURSOR / MCP CONFIG
{
  "mcpServers": {
    "signalforge": {
      "url": "https://signalforge-web-production.up.railway.app/mcp"
    }
  }
